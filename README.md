# Бот наличия обуви для сотрудников

Закрытый Telegram-бот на Python. Владелец выдаёт доступ сотрудникам, сотрудники добавляют фото моделей и изменяют размеры. Все работают с одним каталогом через свои аккаунты Telegram — с телефонов, планшетов и компьютеров.

Для постоянной работы на отдельном Linux-сервере подготовлены [Docker Compose и инструкция переноса](deploy/CLOUD.md). Список выбранных будущих функций хранится в [ROADMAP.md](ROADMAP.md).

## Что умеет

- `/start`: кнопки «В наличии», «Изменить наличие», «Добавить товар».
- Карточка модели: фото, название, номер товара, размеры и количество пар.
- Добавление размеров, удаление размеров, полная замена остатков, новое фото и название.
- Подтверждение перед сохранением; отдельное подтверждение удаления товара из каталога.
- Уведомления с фото, изменениями и именем сотрудника — в рабочую группу или сотрудникам в личные сообщения.
- `/history`: последние изменения. `/status`: очередь уведомлений, доступен владельцу.
- Выдача и отзыв доступа без перезапуска. Без доступа нельзя даже смотреть каталог.
- Сохранение товаров, сотрудников, истории и очереди уведомлений в SQLite. После перезапуска данные остаются.
- Защита от перезаписи чужой правки: если карточка устарела, сотрудник получает просьбу открыть её заново.

## С чего начать — Windows

1. Получите файлы проекта и распакуйте в постоянную папку, например `C:\shop-bot`. Не запускайте файлы прямо внутри ZIP.
2. Установите **Python 3.12** с [python.org](https://www.python.org/downloads/). При установке включите **Add Python to PATH**. Поддерживается Python 3.10 и новее; проверка проекта выполнена на 3.12.
3. В Telegram откройте официального **[@BotFather](https://t.me/BotFather)**. Отправьте `/newbot`, задайте название и username, заканчивающийся на `bot`. Он выдаст токен — ключ управления вашим ботом.
4. Дважды нажмите **`EDIT_SETTINGS.bat`**. Откроется файл `.env` в Блокноте. Если файла ещё нет, он будет создан; существующие настройки сохранятся.
5. В строке `BOT_TOKEN=` вставьте токен после знака `=`. Пока оставьте `OWNER_ID=` пустым. Сохраните файл и закройте Блокнот. Токен не публикуйте и не отправляйте в чаты.
6. Дважды нажмите **`START_BOT.bat`**: установятся зависимости и запустится бот. Оставьте окно запуска открытым. Найдите созданного бота в Telegram и отправьте ему **`/id`**. Он покажет ваш числовой ID.
7. Остановите бота клавишами **Ctrl+C**. Снова откройте **`EDIT_SETTINGS.bat`**, вставьте полученное число после `OWNER_ID=`, сохраните файл.
8. Снова запустите **`START_BOT.bat`** и отправьте своему боту **`/start`**. Теперь вы владелец и видите меню магазина.

Если `.env` уже существует, скрипты его сохраняют. Открыть его можно через `EDIT_SETTINGS.bat` или «Открыть с помощью → Блокнот». Имя файла должно быть `.env`, а не `.env.txt`: в Проводнике включите показ расширений файлов.

Если окно Windows сообщает об отдельных обрезанных командах вроде `'cho'`, `'error'` или `'T_TOKEN'`, обновите `START_BOT.bat` из исправленного архива. Windows-файлы запуска хранятся с окончаниями строк CRLF и командами ASCII, чтобы CMD не искажал их при чтении. При обновлении сохраняйте свой `.env` и папку `data`.

Пока `OWNER_ID` не заполнен, бот никому не показывает товары и позволяет только узнать свой ID. Первый открывший бот не становится владельцем автоматически.

## Как выдать доступ сотруднику

1. Сотрудник открывает вашего бота и отправляет **`/id`**.
2. Он присылает вам полученное число. Токен сотруднику не нужен.
3. Вы пишете вашему боту в личные сообщения: **`/grant 123456789`**, заменив число на ID сотрудника.
4. Сотрудник отправляет боту **`/start`** и получает доступ к каталогу и изменениям.

Только владелец может управлять доступом:

| Команда | Что делает |
| --- | --- |
| `/staff` | Показывает ID сотрудников |
| `/grant 123456789` | Разрешает просмотр и редактирование |
| `/revoke 123456789` | Сразу закрывает просмотр и редактирование; отменяет ожидающие личные уведомления этому сотруднику |

У всех допущенных сотрудников одинаковые права на товары. Управление доступом и подключение рабочей группы остаются у владельца. Отзыв доступа не удаляет уже полученные человеком сообщения и не исключает его из рабочей группы — при увольнении уберите его из группы отдельно.

## Как добавить товар и менять размеры

Нажмите **«Добавить товар»**, отправьте название, одно фото и размеры. Проверьте карточку и нажмите **«Сохранить»**.

| Что написать | Как бот поймёт |
| --- | --- |
| `36, 37, 38` | По одной паре каждого размера |
| `36:2, 37, 38.5:3` | Две пары 36, одна пара 37, три пары 38.5 |
| `-` при полном вводе наличия | Все размеры закончились |

Дробные размеры пишите через точку, например `38.5`. Размеров в карточке может быть до 25, количество каждого — от 1 до 9999.

В разделе **«Изменить наличие»** выберите модель:

- **Добавить размеры** — прибавляет пары к текущему количеству. Например, было `38:2`, добавили `38:1`, стало три пары.
- **Убрать размеры** — убирает все пары выбранных размеров.
- **Задать всё наличие** — заменяет весь список. Чтобы после продажи уменьшить остаток, напишите все оставшиеся размеры и количества.
- **Заменить фото / Название** — меняет карточку.
- **Убрать товар из каталога** — скрывает модель, история остаётся в базе.

Товары без размеров видны в редактировании, но не показываются в разделе «В наличии». Кнопки открывают свежие данные; уже отправленная в переписку карточка сама не обновляется. `/cancel` отменяет несохранённый ввод. При перезапуске незавершённый ввод сбрасывается, сохранённые товары остаются.

## Где будут появляться изменения

По умолчанию выбран режим **рабочей группы**:

1. Создайте закрытую группу Telegram только для сотрудников и добавьте туда бота.
2. Разрешите боту отправлять сообщения и фотографии.
3. От своего аккаунта владельца отправьте в группе **`/notify_here`**. Если ботов несколько, напишите `/notify_here@username_вашего_бота`.
4. При добавлении товара и изменении размеров бот начнёт присылать в группу фото, остатки «было / сейчас» и имя сотрудника.

Чтобы уведомления приходили каждому сотруднику отдельно, в `.env` установите **`NOTIFICATION_MODE=staff`** и перезапустите бота. В этом режиме получатели — владелец и сотрудники с действующим доступом. Каждый должен хотя бы раз открыть бота и нажать `/start`: Telegram запрещает ботам первыми начинать личную переписку.

Временные ошибки сети повторяются автоматически; очередь сохраняется после перезапуска. Постоянная ошибка (например, сотрудник заблокировал бота или группа запретила фото) отражается в `/status`. Такие сообщения не помечаются доставленными. После восстановления прав новые изменения снова отправляются; пропущенные можно посмотреть в `/history`. При сетевом обрыве во время отправки Telegram иногда может принять сообщение без подтверждения — повторная попытка может дать дубликат уведомления, но не дубликат товара.

## Ноутбук вместо сервера

Платный сервер для этого варианта не требуется. Запускайте **одну копию бота** на одном ноутбуке, подключённом к питанию и интернету. Статический IP, открытые порты и настройка роутера не нужны: бот сам получает сообщения из Telegram.

- Сотрудникам достаточно Telegram; Python устанавливается только на ноутбук, где работает бот.
- Отключите автоматический сон ноутбука, в том числе при закрытой крышке. При выключении или пропаже интернета бот недоступен до восстановления работы.
- Для обычного запуска оставляйте окно бота открытым. На Windows для запуска после перезагрузки используйте «Планировщик заданий»: запуск программы `.venv\Scripts\python.exe`, аргументы `-m shoe_shop_bot`, рабочая папка — полный путь к проекту. До создания задачи один раз успешно запустите `START_BOT.bat`. Отключите у задачи ограничение времени работы, запретите параллельные запуски и включите перезапуск при ошибке.
- Не запускайте одновременно бота вручную и через планировщик. Если переносите его на другой ноутбук, сначала остановите старый экземпляр и перенесите базу.
- Фото сохраняются в Telegram, в базе хранится их `file_id`; это работает на разных устройствах с тем же ботом. При создании нового бота с другим токеном старые `file_id` переносить как универсальные фото нельзя.

## Linux и macOS

Из папки проекта:

```bash
bash start.sh
```

При первом запуске создастся `.env`. Заполните `BOT_TOKEN`, повторите запуск, узнайте `/id`, остановите бота, заполните `OWNER_ID` и запустите снова. На Debian/Ubuntu для создания окружения может понадобиться пакет `python3-venv`.

Ручной запуск с уже установленными зависимостями:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m shoe_shop_bot
```

Для постоянной работы Linux подготовлен пример [systemd-службы](deploy/shoe-shop-bot.service.example). Укажите своего пользователя и реальные пути, затем установите файл как службу. Это пример для настройки на вашем ноутбуке; текущая облачная сессия не является постоянно работающим сервером.

## Резервная копия и перенос

В папке проекта на Windows:

```powershell
.venv\Scripts\python.exe -m shoe_shop_bot.backup
```

На Linux/macOS:

```bash
.venv/bin/python -m shoe_shop_bot.backup
```

Будет создан файл в `backups/`. Команда использует механизм SQLite backup: копия включает подтверждённые изменения, даже если бот работает и база использует WAL. Храните копию отдельно от ноутбука. База содержит данные магазина, ID сотрудников и настройки уведомлений.

Для переноса остановите старый бот, скопируйте проект и `.env` на новый ноутбук, создайте на нём папку `data` и положите копию базы под именем `shop.sqlite3` (либо используйте свой `DATABASE_PATH`). Затем установите зависимости и запустите бота на новом ноутбуке. Окружение `.venv` между компьютерами не копируйте — создайте заново. Не подменяйте базу работающего процесса и не копируйте отдельно живой `shop.sqlite3`, забыв про `-wal`.

## Проверка проекта

```bash
python -m pip install -r requirements.txt
python -m unittest discover -v
```

Тесты работают без настоящего токена и без обращений в Telegram. Они проверяют полный сценарий добавления товара через обработчики Telegram, фото и размеры, права владельца и сотрудников, отзыв доступа, конфликты одновременных правок, резервную копию и повторную доставку уведомлений. Подключение к настоящему Telegram проверяется отдельно после настройки токена.
