БОТ МАГАЗИНА — ЗАПУСК НА WINDOWS

1. Распакуйте архив в постоянную папку, например C:\shop-bot.
2. Установите Python 3.12 с python.org. Поставьте галочку Add Python to PATH.
3. В Telegram откройте официального @BotFather и отправьте /newbot.
   Придумайте имя и username бота. Сохраните выданный токен в тайне.
4. Откройте EDIT_SETTINGS.bat. Появится Блокнот с файлом .env.
   Вставьте токен в строку BOT_TOKEN=, сразу после знака =.
   Сохраните файл и закройте Блокнот. Запустите START_BOT.bat.
   Окно бота оставьте открытым.
5. Найдите СВОЕГО нового бота в Telegram. Напишите ему /id.
6. В окне бота нажмите Ctrl+C. Снова откройте EDIT_SETTINGS.bat.
   Вставьте ваше число из /id в строку OWNER_ID=. Сохраните файл.
7. Снова запустите START_BOT.bat. Напишите своему боту /start.

ДОСТУП СОТРУДНИКАМ

Сотрудник открывает /start и нажимает «Запросить доступ».
Вам придёт сообщение с кнопками «Разрешить» / «Отказать».
Можно также по-старому попросить сотрудника написать /id.
Он передаст вам число. Вы отправляете своему боту:
  /grant ЧИСЛО_СОТРУДНИКА
Теперь сотрудник может открыть /start и работать с товарами.
Закрыть доступ: /revoke ЧИСЛО_СОТРУДНИКА
Посмотреть список сотрудников: /staff
Токен сотрудникам не передавайте.

УВЕДОМЛЕНИЯ

Добавьте бота в закрытую рабочую группу Telegram.
От своего аккаунта владельца напишите в этой группе /notify_here.
После этого новые товары и изменения будут появляться в группе.
Состав группы контролируете вы; удаляйте из неё уволенных сотрудников.

РАЗМЕРЫ

38, 39, 40 — по одной паре.
38:2, 39, 40.5:3 — две пары 38, одна 39, три пары 40.5.
Всё вводится кнопками в боте. /cancel — отменить ввод.

Ноутбук с ботом должен быть включён, не спать и иметь интернет.
Сотрудники работают со своих устройств через Telegram.
Не запускайте две копии бота одновременно.

НОВЫЕ КНОПКИ

Продано — выбрать товар, размер/количество и цену за ОДНУ пару в гривнах.
Можно добавить несколько позиций. Остатки изменятся после подтверждения.
Продажи и возвраты — вернуть часть продажи или отменить ошибочную.
Поиск — название, размер или номер товара. Разделы — по брендам.
Внутри списков по умолчанию названия по алфавиту.
QR и штрихкоды НЕ ОБЯЗАТЕЛЬНЫ. Их можно добавить позже в карточке товара.
Отчёты — день, неделя, месяц или даты; выручка и популярные модели.
Отчёт владельцу — каждый день в 21:00 по Киеву.
Изменить время: /report_time 21:30. Отключить: /report_time off.
/backup — получить копию базы (только владелец).
Автоматические копии — при запуске и раз в 6 часов, в data/backups.

АВТОЗАПУСК НА ЭТОМ НОУТБУКЕ (ПО ЖЕЛАНИЮ)

Сначала успешно запустите обычный START_BOT, затем остановите Ctrl+C.
Откройте ENABLE_AUTOSTART: бот запустится в фоне и после входа в Windows.
Отключить и остановить фоновую работу: DISABLE_AUTOSTART.
До входа в учётную запись Windows бот этим способом не запускается.

Для обновления существующего бота: UPDATE_RU.txt.
Подробности, Linux, резервные копии и перенос: README.md.
