БОТ МАГАЗИНА — ЗАПУСК НА WINDOWS

1. Распакуйте архив в постоянную папку, например C:\shop-bot.
2. Установите Python 3.12 с python.org. Поставьте галочку Add Python to PATH.
3. В Telegram откройте официального @BotFather и отправьте /newbot.
   Придумайте имя и username бота. Сохраните выданный токен в тайне.
4. Откройте START_BOT.bat. При первом запуске появится Блокнот.
   Вставьте токен в строку BOT_TOKEN=, сразу после знака =.
   Сохраните файл и закройте Блокнот. Окно бота оставьте открытым.
5. Найдите СВОЕГО нового бота в Telegram. Напишите ему /id.
6. В окне бота нажмите Ctrl+C. Откройте файл .env через Блокнот.
   Вставьте ваше число из /id в строку OWNER_ID=. Сохраните файл.
7. Снова запустите START_BOT.bat. Напишите своему боту /start.

ДОСТУП СОТРУДНИКАМ

Попросите сотрудника открыть вашего бота и написать /id.
Он передаст вам число. Вы отправляете своему боту:
  /grant ЧИСЛО_СОТРУДНИКА
Теперь сотрудник может открыть /start и работать с товарами.
Закрыть доступ: /revoke ЧИСЛО_СОТРУДНИКА
Посмотреть список сотрудников: /staff
Токен сотрудникам не передавайте.

УВЕДОМЛЕНИЯ

Добавьте бота в закрытую рабочую группу Telegram.
От своего аккаунта владельца напишите в этой группе /notify_here.
После этого новые товары и изменения будут появляться в группе.
Состав группы контролируете вы; удаляйте из неё уволенных сотрудников.

РАЗМЕРЫ

38, 39, 40 — по одной паре.
38:2, 39, 40.5:3 — две пары 38, одна 39, три пары 40.5.
Всё вводится кнопками в боте. /cancel — отменить ввод.

Ноутбук с ботом должен быть включён, не спать и иметь интернет.
Сотрудники работают со своих устройств через Telegram.
Не запускайте две копии бота одновременно.

Подробности, Linux, резервные копии и перенос: README.md.
