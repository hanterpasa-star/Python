КАК ОБНОВИТЬ БОТА И СОХРАНИТЬ ТОВАРЫ

Не создавайте нового бота в BotFather. Используйте своего прежнего бота и токен.

1. Пока старый бот ещё работает, откройте папку проекта, в которой лежит START_BOT.
   Для дополнительной копии базы можно в адресной строке этой папки написать cmd,
   нажать Enter и в чёрном окне выполнить:
   .venv\Scripts\python.exe -m shoe_shop_bot.backup
   Сохраните получившийся файл из папки backups отдельно.

2. Остановите старый бот: в его чёрном окне нажмите Ctrl+C.
   Если Windows спросит Y/N — нажмите Y и Enter.
   Если был настроен фоновый запуск, сначала откройте DISABLE_AUTOSTART.

3. Скачайте новый архив:
   https://github.com/hanterpasa-star/Python/archive/refs/heads/main.zip
   Нажмите на скачанный ZIP правой кнопкой → Извлечь всё.
   Откройте распакованную папку, где виден START_BOT.

4. Скопируйте ВСЕ файлы и папки из нового архива В СТАРУЮ рабочую папку бота.
   Когда Windows спросит о замене файлов, выберите «Заменить».
   Не удаляйте старую папку, свой .env и папку data!
   В архиве нет вашего .env и data — настройки, товары и сотрудники сохранятся.
   Папку .venv оставьте на месте, если обновляете на том же ноутбуке.

5. В прежней рабочей папке откройте START_BOT.
   Он обновит зависимости. При первой загрузке старой базы сделает её копию,
   затем сохранит товары и добавит учёт продаж.
   В Telegram напишите /start — появятся новые кнопки.

QR и штрихкоды полностью удалены. Библиотека zxing-cpp больше не нужна.
Обычное добавление: название → фото → размеры → Сохранить.
Раздел бренда: Изменить наличие → товар → Раздел.
В списках по умолчанию названия по алфавиту.
Продано: выбрать товар → размер/количество → цена за одну пару в гривнах
→ при необходимости Ещё товар → Подтвердить продажу.
Возврат / отмена: Продажи и возвраты → нужная продажа.
Отчёт владельцу: ежедневно в 21:00 по Киеву.
Получить резервную копию в Telegram: /backup (только владелец).

Для автозапуска после входа в Windows: остановите обычный бот,
затем откройте ENABLE_AUTOSTART. Отключить: DISABLE_AUTOSTART.
Ноутбук должен оставаться включённым, не спать и иметь интернет.
Рекомендуется Python 3.12 (64-bit) и Windows 10/11.
Проверяются Python 3.10/3.12, в том числе 32-битный Python 3.12.
Сервер сейчас подключать не нужно.
