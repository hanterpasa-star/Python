# Выбранные изменения

Выбранные функции реализованы в текущем коде и проверяются тестами. На ноутбуке владельца они появятся после обновления файлов и перезапуска бота. Автозапуск включается отдельно файлом ENABLE_AUTOSTART.bat; на этом ноутбуке он из облачной сессии не установлен.
Номера сохранены из обсуждения с владельцем.

| № | Функция |
| --- | --- |
| 1 | «Продано»: выбрать товар, размер и количество; сохранить продажу и уменьшить остаток |
| 3 | Поиск по названию, размеру и номеру товара |
| 7 | Отчёт за день: проданные пары и выручка |
| 8 | Автоматические резервные копии |
| 9 | Возврат: восстановить остатки и учесть возврат в отчёте |
| 11 | Уведомление о последней паре или низком остатке размера |
| 13 | Автозапуск и восстановление процесса после перезагрузки или сбоя |
| 15 | Предупреждение о возможном дубликате при добавлении товара |
| 16 | Запрос доступа с кнопками владельца «Разрешить» / «Отказать» |
| 17 | Отмена ошибочной продажи с восстановлением остатков и исправлением отчёта |
| 18 | Отчёты за выбранный период, неделю и месяц |
| 19 | Популярные модели и размеры по продажам |
| 21 | Автоматический вечерний отчёт в выбранное время |
| 24 | Несколько товаров и размеров в одной продаже |
| 25 | Разделы каталога по брендам или типам обуви |
| 29 | Открытие карточки по штрихкоду или QR-коду |
| 30 | Сводка текущих остатков: модели и пары |
| 32 | Расширенный статус: имя сервера, время работы и последняя резервная копия |

Валюта продаж — гривны (UAH), цена вводится за одну пару при оформлении продажи.
Вечерний отчёт — в 21:00 по Киеву, владельцу в личные сообщения; время меняется через `/report_time`.
QR-коды и штрихкоды необязательны. Каталог разделён по брендам / типам, внутри по умолчанию сортируется по алфавиту.
Автоматические копии лежат рядом с базой; `/backup` позволяет владельцу сохранить файл отдельно.
Копия на том же диске не защищает от потери самого ноутбука.

## Постоянный запуск

Владелец отложил перенос на сервер до проверки новых функций бота. Ранее разрешил рассмотреть бесплатный хостинг с проверкой банковской карты.
Подготовлено развёртывание текущего бота на Linux-сервере через Docker Compose:
[инструкция](deploy/CLOUD.md). Для запуска нужен аккаунт владельца и доступный сервер.
Подготовка файлов не означает, что сервер уже создан или бот перенесён с ноутбука.
